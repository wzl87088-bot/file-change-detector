# 文件变化检测器

我的第一个 Python 小项目：使用 SHA-256 指纹和 JSON 快照，检测文件的新增、删除和内容修改。

## 功能

- 首次运行自动创建快照。
- 再次运行时，对比当前文件与旧快照。
- 输出新增、删除或修改的文件名；没有变化时显示提示。
- 检测到变化后，可以选择更新快照，或保留旧记录。

## 运行

需要 Python 3，无须安装第三方依赖。在项目文件夹中运行：

```bash
python main.py
```

程序检查脚本旁边的 `test_files` 文件夹。首次运行会生成 `snapshot_backup.json`；这是当前代码实际使用的快照文件名。

## 体验方法

1. 首次运行，建立快照。
2. 在 `test_files` 中新增文件、修改已有文件，或删除文件。
3. 再次运行，查看检测结果。
4. 输入 `y` 更新快照，其他输入保留旧快照。输入不区分大小写，并会去掉两端空白。
5. 更新后不再修改文件，再次运行会显示“未发现变化”。保留旧快照时，下次会继续报告尚未记录的变化。

## 当前范围

只检查 `test_files` 直接包含的文件，不递归检查子文件夹。检查需要手动运行程序。目前要求测试文件夹存在，快照是有效 JSON，且文件可读取。

快照在本机生成，不上传到仓库。示例文本仅用于练习。
